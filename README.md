# 📌 Project Overview

LifeOS is an AI-powered Behavioral Operating System developed during the **Tynovate AI Internship 2026**.

The project collects behavioral data from multiple sources, analyzes user activity patterns, predicts future behavior using Machine Learning, and provides adaptive interventions to improve productivity.

The project follows **Clean Architecture**, **Modular Programming**, and **Software Engineering Best Practices**.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/YasmeenGull/LifeOS.git
```

## Install Requirements

```bash
pip install -r requirements.txt
```

## Run Project

```bash
python src/main.py
```
## Run Dashboard

```bash
streamlit run src/dashboard/app.py
```

---

# 🐳 Docker

# Build image
docker build -t lifeos .

# Run container
docker run -p 8000:8000 lifeos

> Docker Desktop is required to run these commands.

# 📡 API Documentation
After starting the server:

```bash
uvicorn src.api.app:app --reload
```

Open:

```
http://127.0.0.1:8000/docs
```

Interactive API documentation is automatically generated using **Swagger UI**.

Available endpoints include:

- GET /
- POST /log
- GET /logs
- GET /score
- GET /debt
- POST /goals
- GET /goals
